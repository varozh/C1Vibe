# План отгрузки товаров в магазины Business Line (19.11.2026)

Задача: по остаткам и продажам Розницы предложить план отгрузки в каждый магазин с учётом сроков доставки. До Урала (Екатеринбург, Пермь, Челябинск), Сочи и Санкт-Петербурга товар идёт 1,5–2 недели, до остальных магазинов, включая Уфу и Оренбург, — 1 неделя.

Сделано: выгружены продажи за 13 недель, остатки и товары в пути 33 магазинов Business Line и «ОФИС» из Розницы, а также остаток «Главного розничного склада» из УТ. По каждому размеру модели рассчитана потребность (скорость продаж × 1,2 на декабрь × срок доставки + 1 неделя) и распределена по наличию на ЦС. Добавлены новинки, которых нет в магазине, перемещения между магазинами под дефицит ЦС и список размеров для дошива.

- `План_отгрузки_2026-11-19.xlsx` — итоги по магазинам с волнами отгрузки, построчный план, перемещения, дефицит ЦС, методика.
- `Анализ_остатков_и_план_отгрузки_2026-11-19.pdf` — отчёт: избыток товара в магазинах и нехватка продаваемых размеров, план по волнам, дефицит ЦС, рекомендации.
- `Остатки_без_продаж_размера_13нед_2026-11-19.xlsx` — 75 058 шт. остатка магазинов, у которых размер не продавался в этом магазине 13 недель: сводка по магазинам, коллекциям и группам, построчный список с категорией (недавно поступил / старая коллекция / модель продаётся, размер нет / модель не продаётся).
- `src` — выгрузка из 1С (`export1c.ps1`, запросы в `q`), расчёт (`analyze.ps1`), показатели для отчёта (`stats.ps1`), сборка Excel (`build_xlsx.ps1`) и PDF (`build_pdf.ps1`).

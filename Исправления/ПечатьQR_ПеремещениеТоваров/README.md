# Печать QR кода маркировки в перемещении товаров (Розница 1.0)

Кнопка «Печать QR» в форме перемещения портила base64-код марки: разделители групп вставлялись прямо в base64-строку. Исправлено в модуле формы `Документ.ПеремещениеТоваров.ФормаДокумента` и в процедуре `ДополнитьКодМаркировкиРазделителямиГрупп` общего модуля `УмКо_РаботаСМаркировкой` (метка `Claude 17.11.2026`).

- `*.bsl` — исправленные модули, `*.orig.bsl` — исходные, `Form.bin` — форма с исправленным модулем (по выгрузке 17.11).
- `apply-to-dump.ps1` — вносит те же правки точечно в любую XML-выгрузку Розницы; используется при сборке `.cf` в `..\АнализПродажИОстатков_Розница\config\make-cf.ps1`.

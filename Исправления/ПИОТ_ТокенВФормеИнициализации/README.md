# ПИОТ: токен в форме инициализации локального модуля

Внешняя обработка «Инициализировать локальный модуль» (Розница) брала токен авторизации только из регистра
`НастройкиРазрешительногоРежимаМагазинов`. На форму добавлено поле «Токен» под магазином: если оно заполнено,
для инициализации берётся этот токен, если пустое — токен из регистра, как раньше. Регистр обработка не меняет.
После выполнения выводится результат (ошибка или «инициализирован»).

- `ИнициализироватьЛокальныйМодуль.epf` — готовая обработка.
- `ИнициализироватьЛокальныйМодуль_МодульФормы.bsl` — модуль формы.
- `ИнициализироватьЛокальныйМодуль_исходная.epf`, `build.ps1` — исходник и сборка (`-RetailBase` — файловая база с конфигурацией Розницы).

# Бот MAX: контроль обмена магазинов с центральной базой Розницы

Магазины не всегда выполняют обмен утром и вечером, и в центральной базе не хватает данных.
Скрипт `exchange-bot.ps1` отправляет сообщения в общую группу магазинов в MAX:
- в 20:00 (`-Mode Reminder`) — напоминание всем выполнить обмен после закрытия смены;
- в 07:00 (`-Mode Report`) — список магазинов, данные которых не загружались в центральную базу после 20:00 прошлого дня.

Дата обмена берётся из `РегистрСведений.ИсторияОбменаДанными` (последняя успешная загрузка по узлу плана обмена `ПоМагазину`). Это та же дата, что «Последняя удачная загрузка данных» в форме «Выполнение обмена данными».
В список попадают только магазины BL, без SoLi's, Gesolina, ОФИС, помеченных на удаление узлов и магазинов без единого обмена (ещё не открыты). Дополнительные исключения задаются в `exclude` в `config.json`.
Подключение к базе, токен бота и группа задаются в `config.json`. Пароль 1С и токен хранятся в зашифрованном виде (DPAPI). Режимы `Check` и `InstallTasks` проверяют окружение и создают задачи в Планировщике. Установка на сервер описана в `ИНСТРУКЦИЯ.md`.

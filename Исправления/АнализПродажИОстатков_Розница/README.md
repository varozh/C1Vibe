# Анализ продаж и остатков (+) — в конфигурацию Розницы 1.0

Внешний отчёт «Анализ продаж и остатков (цены на 5 и на 0)» перенесён в конфигурацию как отчёт `БЛ_АнализПродажИОстатков` с синонимом «Анализ продаж и остатков (цены на 5 и на 0) (+)». Он добавлен последней строкой подменю «Отчеты для товароведов» в интерфейсе «Полный».

- `АнализПродажИОстатков.erf` — исходный внешний отчёт, его XML лежит в `src`.
- `config\БЛ_АнализПродажИОстатков_МодульОбъекта.bsl` — модуль объекта. Схема компоновки — без изменений, собственной формы у отчёта нет.
- `config\src` + `files.txt` — XML доработки (отчёт, `Configuration.xml`, интерфейс «Полный»). Их генерирует `config\build-config.ps1`.
- `Розница_АнализПродажИОстатков_QR.cf` (по запросу, 19.11.2026) — конфигурация рабочей базы на 19.11 с этим отчётом и с исправлением печати QR из `..\ПечатьQR_ПеремещениеТоваров`. Собирает `config\make-cf.ps1`: .cf рабочей базы, затем частичная загрузка только изменённых объектов, так что остальные объекты не пересобираются через XML.
- `Розница_АнализПродажИОстатков.cf` — первая сборка (18.11, полная загрузка из XML, без QR), заменена предыдущей.
- Роли не менялись: доступ к отчётам этого подменю есть только у ролей с правами на новые объекты (ПолныеПрава и т. п.).

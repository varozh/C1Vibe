# Выплата по возвратам: чек только после подтверждения эквайринга

Розница 1.0, обработка «Меню РМК», кнопка «Выплата» (процедура `ВыплатаНажатие` модуля формы).

Раньше фискальный чек возврата печатался до операции на терминале. Если терминал не отвечал, чек оставался пробитым, а ряд ошибок терминала засчитывался как успешная выплата.

Сделано:
- `МенюРМК_МодульФормы.bsl` — новая `ВыплатаНажатие` и вспомогательные функции. Порядок теперь такой: проверки ККТ и смены → возврат на терминале → чек → проведение. Если терминал вернул деньги, а чек не пробился, повторное нажатие «Выплата» печатает только чек. Признаки хранятся в комментарии документа оплаты картой: `#ТЕРМИНАЛ_ОК` и `#ТЕРМИНАЛ_ОШИБКА`.
- Через терминал теперь идут и возвраты продаж, пробитых по старым договорам эквайринга магазина.
- `МенюРМК_МодульФормы_orig.bsl` — исходная процедура.

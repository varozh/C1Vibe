# Анализ остатков товаров на складах (ШК 46) — УТ 10.3

Копия отчёта «Анализ доступности товаров на складах»: только фактический остаток, группировки Склад → Номенклатура → Характеристика, колонки штрихкодов 46 организаций ООО Талисман, ИП Ланков Е.В., ИП Зубарева Е.В. (каждая включается флажком в отборах).

- `АнализОстатковТоваровНаСкладахШК.erf` — внешний отчёт, исходники в `src`.
- `config\БЛ_АнализОстатковТоваровНаСкладахШК_МодульОбъекта.bsl` — модуль объекта отчёта `БЛ_АнализОстатковТоваровНаСкладахШК` для конфигурации (форма — копия формы исходного отчёта без изменений), пункт последней строкой меню «Отчеты» интерфейса «Полный».

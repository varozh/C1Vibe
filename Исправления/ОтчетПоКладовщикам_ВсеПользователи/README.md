# Отчёт по кладовщикам — все пользователи (УТ 10.3, внешний отчёт)

Задача: копия `Отчеты.ОтчетПоКладовщикам` внешним отчётом, где ответственные по отгрузкам и приёмке ищутся среди всех пользователей, а не только в группе пользователей «Склады» (код `SKLAD`).

Сделано:
- `ОтчетПоКладовщикамВсеПользователи.erf`: внешний отчёт «Отчет по кладовщикам (все пользователи)». Копия текущего отчёта конфигурации, флажок «По дням» сохранён.
- Схема: отбор `Ответственный В ИЕРАРХИИ(&Ответственные)` заменён условием «ответственный заполнен», параметр «Ответственные» удалён.
- `ОтчетПоКладовщикамВсеПользователи_МодульФормы.bsl`: модуль формы, в котором больше не заполняется группа `SKLAD`.
- Расшифровка, как в типовых отчётах УТ («Анализ доступности товаров на складах»): двойной щелчок по ячейке открывает ещё один экземпляр этого отчёта с группировкой Ответственный → Склад → Документ (перемещения, приходные и расходные ордера) и отбором по ответственному и складу ячейки; день ячейки становится периодом. В отчёте-расшифровке двойной щелчок по строке документа открывает документ. Код — `Расшифровка.bsl` (build.ps1 добавляет его в модуль формы), в схеме — поле «Документ» и параметр «ПоДокументам». Строки складов в обычном режиме выводятся группировкой «Склад» вместо детальных записей, чтобы склад попадал в отбор расшифровки; цифры отчёта при этом те же.
- `build.ps1`: собирает исходники (`src`) из выгрузки `УТ` и, если указан `-UtBase`, сам `.erf`.

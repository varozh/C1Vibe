# Перекодировка дублей кодов информационных карт (Розница 1.0)

Внешняя обработка `ПерекодировкаДублейИнфКарт.epf` для 1С:Розницы 1.0 (база `bl-isoflex/retail`, платформа 8.3.12).
Она ищет в справочнике «Информационные карты» записи с одинаковым основным кодом (`Код`). В каждой группе дублей одной записи префикс кода (первые 3 символа) заменяется на **БЕЕ**, остальные записи не меняются. Пример: `Бвм997522` → `БЕЕ997522`. Номер карты (`КодКарты`) не меняется.

- `src\` — исходники, вся логика в `src\ПерекодировкаДублейИнфКарт\Ext\ObjectModule.bsl`. Формы нет: диалоги открываются сразу при открытии файла.
- Сборка: `1cv8.exe` 8.3.12, `DESIGNER /F <любая пустая база> /LoadExternalDataProcessorOrReportFromFiles src\ПерекодировкаДублейИнфКарт.xml ПерекодировкаДублейИнфКарт.epf`.

## Как пользоваться

1. Войдите в Розницу пользователем с полными правами (нужно и право «Редактировать регистрационные карты») и откройте файл через «Файл → Открыть».
2. **Магазины.** Отметьте магазины, чьи карты нужно перекодировать в первую очередь, или ничего не отмечайте.
3. **Список дублей.** В каждой группе галочкой отмечена запись, которой поменяется код. Галочки можно переставить. Если в группе отмечено ноль или больше одной записи, эта группа пропускается.
4. Подтвердите. Результат по каждой карте появится в окне сообщений и в журнале регистрации (событие `ПерекодировкаДублейИнфКарт`).

**Группы с картой, помеченной на удаление, не меняются целиком**: ни помеченная, ни непомеченная карта кода не меняют, даже если в списке отметить их вручную. Кроме того, перед записью пометка удаления у самой карты проверяется еще раз.

Какая запись отмечается по умолчанию (правила применяются по очереди, пока не останется одна):
1. карта магазина, выбранного на шаге 2;
2. карта с более поздней датой открытия (при равных датах — последняя по порядку ссылок).

## Как записывается

- Каждая карта записывается отдельно, обычной записью: изменения регистрируются к обмену и уходят в узлы РИБ.
- Перед записью обработка проверяет, что новый код свободен. Если код уже занят или запись успели изменить, карта пропускается с сообщением.
- Обработку можно запускать повторно: она найдет только оставшиеся дубли.

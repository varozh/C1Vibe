# Перемещение дублей контрагентов в папку «Дубли» (БП 3.0)

Внешняя обработка `ПеремещениеДублейКонтрагентов.epf`. Она переносит в папку «Дубли» (BE-001666) карточки контрагентов, помеченные на удаление после объединения в «Поиске и удалении дублей», и дописывает к их наименованию « дубль». Код, ИНН, полное наименование и пометка удаления не меняются, а к обмену с УТ изменение не регистрируется.

Список карточек зашит в модуль формы (`Код|Наименование`). Это карточки, которые входили в группы дублей и не были помечены на удаление на момент прогона: 274 карточки из прогона 17.11.2026 и 22 из прогона 18.11.2026.

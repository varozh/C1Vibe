# Удаление непроведенных поступлений, загруженных из УТ (БП 3.0)

Внешняя обработка `УдалениеПоступленийБП.epf` для 1С:Бухгалтерия предприятия 3.0 (bl-morion/buh30, платформа 8.3.27).
Исходники — `src\` (собрано: `1cv8 DESIGNER /LoadExternalDataProcessorOrReportFromFiles`).

Зачем: уже загруженные поступления обмен не перезаписывает (в правилах «Не замещать»). Чтобы они пришли заново
по исправленным правилам, их нужно удалить в БП и повторно выгрузить из УТ.

## Порядок

1. Сделать копию базы БП.
2. БП → Файл → Открыть → `УдалениеПоступленийБП.epf` (или «Дополнительные обработки»).
3. Отбор: дата с (по умолчанию 31.12.2025), ИНН организаций (Ланков, Талисман, Зубарева), при необходимости — конкретные номера,
   флажок «Только загруженные из УТ», условие:
   - «Есть строки "Зачет авансов" без документа аванса» — 480 поступлений с ошибкой проведения;
   - «Не заполнены счета учета / счет расчетов или склад "Объект не найден"» — например, СМАРТ-Т УТЕВ0001457, 1458;
   - «Любое из этих условий» / «Все непроведенные».
4. «Найти поступления» → проверить список (колонки «Что не так», «Счета-фактуры»), снять лишние отметки.
5. Режим:
   - «Пометить на удаление» — безопасно, можно вернуть;
   - «Удалить окончательно» — документ удаляется, только если на него нет ссылок из других документов/справочников
     (кроме его собственного счета-фактуры). Уже помеченные на удаление в этом режиме тоже показываются.
6. «Выполнить для отмеченных» → подтвердить. Итог — в колонке «Результат».

Для повторной загрузки нужен именно режим «Удалить окончательно»: помеченный на удаление документ обмен найдет по идентификатору и не заменит.

## Что гарантирует обработка

- Проведенные поступления не трогает (проведенный счет-фактура к поступлению перед удалением распроводится).
- Изменения не регистрируются к обмену (`ОтключитьМеханизмРегистрацииОбъектов`, `ОбменДанными.Загрузка`) — пометка и удаление не уйдут в УТ.
- Счет-фактура удаляется вместе с поступлением, только если все его основания среди отмеченных поступлений.
- Каждое поступление со своим счетом-фактурой — отдельная транзакция; ошибки пишутся в журнал регистрации
  (событие «Удаление поступлений из УТ»).

## После удаления

В УТ перепровести (перезаписать) эти поступления — они зарегистрируются к обмену — и выполнить синхронизацию с правилами
`Правила Обмена ут-бух 12112026.xml`.

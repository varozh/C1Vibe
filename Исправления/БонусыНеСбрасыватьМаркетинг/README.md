# Окно бонусов не должно сбрасывать скидки маркетинга (Розница 1.0)

Окно бонусов РМК (`ЧекККМ`, форма `ФормаДК`) при кнопке «Отмена» и при «Распределить скидку» с нулевой суммой бонусов возвращало товарам полную цену. Из-за этого пропадали скидки маркетинга (флаг «Маркетинг»), например скидки акции на платья.

Правка в `ЧекККМ_ФормаДК_МодульФормы.bsl`:
- «Отмена» не трогает сумму товара, если на нём действует скидка маркетинга;
- «Распределить скидку» без бонусов закрывает окно так же, как «Отмена».

Закрытие окна крестиком эта правка не меняет: при закрытии крестиком скидки и раньше не сбрасывались. Скидка со второго платья в ОФИС 20.11.2026 пропадала из-за «Значение условия макс» = 1 у скидки 1703, а не из-за окна бонусов.

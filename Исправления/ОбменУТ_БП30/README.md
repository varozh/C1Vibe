## Как загрузить

1. УТ → Администрирование → Синхронизация данных → узел «BUH EV 3.0» → Правила конвертации объектов → «Загрузить правила из файла» → выбрать `Правила Обмена ут-бух 06112026.xml`.

3. Откат — загрузить `Исходные\Правила Обмена ут-бух 29012026 v2.xml`.

# Отчёт по кладовщикам — флажок «По дням» (УТ 10.3)

Задача: в `Отчеты.ОтчетПоКладовщикам` добавить настройку, чтобы принятые и собранные выводились по каждому дню, а итог за период стоял первой и последней колонкой.

Сделано:
- `ОтчетПоКладовщикам_МодульФормы.bsl`: новый модуль формы. Если флажок включён, процедура `НастроитьВыводПоДням` строит таблицу: в строках ответственный → склад, в колонках дни, итог за период в начале и в конце.
- `ОтчетПоКладовщикам_ЗапросСКД.txt`: запрос схемы с полем «День» (заполняется только при параметре `ПоДням`).
- `УТ_ОтчетПоКладовщикам.cf` (по запросу): конфигурация УТ с изменённым отчётом, собирается `config\make-cf.ps1` из `config\src` (их генерирует `build.ps1`).
- `ОтчетПоКладовщикам.erf` и `build.ps1`: внешняя копия отчёта с этими изменениями, чтобы проверить его до переноса.

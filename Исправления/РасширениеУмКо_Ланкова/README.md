# Исправление расширения УмКо_Ланкова (БП 3.0, bl-morion/buh30)

- `УмКо_Ланкова_1.0.0.1.cfe` — исходная версия, сохранена из БП 13.11.2026 (для отката).
- `УмКо_Ланкова_1.0.0.2.cfe` — исправленная.
- `src\` — XML-исходники исправленной версии.

## Что было не так

Загрузка из УТ обрывалась исключением, а в БП выключено «продолжать при ошибке». Поэтому БП не принимала
сообщения 3356–3358 целиком: номер сообщения не засчитывался, всё, что шло после ошибки, не загружалось.

1. `КонвертацияОбъектовИнформационныхБаз`, `Расш1_НайтиОбъектПоСсылке`, строка 882:
   `Если СозданныйОбъект.Проведен Тогда` — если документ, сопоставленный с УТ, удалён в БП,
   `ПолучитьОбъект()` возвращает Неопределено → «Значение не является значением объектного типа (Проведен)».
2. То же, `Расш1_НайтиИлиСоздатьОбъектПоСвойству`, строка 633: `Если Объект.Проведен Тогда` при Объект = Неопределено.
3. `УмКо_ПодпискиНаСобытия`, строка 15: `НомОб.ОбменДанными.Загрузка = Истина` — номенклатура из штрихкода упаковки
   ещё не загружена (битая ссылка) → `ПолучитьОбъект()` = Неопределено.

## Что изменено (1.0.0.2)

Только проверки на Неопределено в этих трёх местах; логика расширения та же.
Проверено: файл собирается и распаковывается обратно без других отличий от 1.0.0.1.
Не проверено: компиляция на конфигурации БП (в пустой базе заимствованных объектов нет) — проверится при установке.

## Поведение расширения, которое важно знать

- Проведённые в БП документы `РеализацияТоваровУслуг`, `КорректировкаРеализации`, `ОтчетОРозничныхПродажах`,
  `ПоступлениеТоваровУслуг` при повторной загрузке из УТ **не перезаписываются** (пропускаются).
  Непроведённые — перезаписываются.
- Контрагенты ищутся по Наименованию + ИНН, а не по GUID.
- Расширение также заменяет макет `ПравилаОбменаКорреспондента` плана обмена.
- Подписка: при загрузке поступлений и реализаций ставит «Способ зачета авансов = Автоматически».

## Установка

1. Сделать копию базы БП.
2. БП → Администрирование → Печатные формы, отчеты и обработки → Расширения.
3. Выделить «УмКо_Ланкова» → Ещё → **Обновить из файла на диске…** → `УмКо_Ланкова_1.0.0.2.cfe`.
4. Перезапустить БП (сеансам — перезайти, фоновые задания подхватят после перезапуска сеансов).
5. Запустить синхронизацию с УТ. БП должна принять сообщение 3358 (проверка: в БП узел UT, НомерПринятого ≥ 3358).

Откат — то же самое с файлом `УмКо_Ланкова_1.0.0.1.cfe`.
